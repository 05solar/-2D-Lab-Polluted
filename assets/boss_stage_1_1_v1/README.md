# 보스 1-1: 원심 배양체 C-01

기존 몬스터를 확대하지 않은 별도 연구소 보스 아트와 패턴/광장/단계 진행 초안, 구현 프롬프트를 제공한다. 게임 코드 적용은 포함하지 않는다.

본체·가구·VFX·바닥·HP 프레임은 이미지 생성 도구로 제작했다. 예고 도형·HP 채움·돌진 잔상·보상 빛은 판정 범위와 UI 크기를 정확하게 맞추기 위해 코드로 제작했다. 공용 패널/버튼/노드 테두리는 앞 단계 팩을 재사용했다.

## 초기 밸런스 초안

- 보스 HP600. 플레이어의 기존 공격력/스킬/강화/최대HP는 유지한다.
- 시약 투척: 예고0.8초,0.5초 조준 고정,3발 순차 발사, 피해20, 기둥 차단.
- 오염 장판: 예고1초, 반경2.2타일,4초 유지,0.5초마다8피해. 기둥 뒤도 위험하지만 기둥 본체 셀은 제외.
- 돌진: 예고0.9초,0.55초 조준 고정, 최대8타일, 피해30. 기둥/벽에서 정지 후0.9초 회복.

수치와 비용이 아닌 보상 풀 참조는 JSON에서 조정한다. 실제 고가 아이템의 이름·가격·가중치는 기존 loot 카탈로그를 사용한다. 신규 아이템 아트나 가격표는 이 팩에 만들지 않았다.

## 적용

1. 폴더와 구현 프롬프트를 개발 AI에게 전달한다.
2. 기존 메인 컴퓨터 Space 상호작용·스킬·전투·저장·본부 보관함에 연결한다.
3. 프레임은 좌상단에서 행 우선으로 자른다.192/128셀을 trim하거나 프레임마다 확대하지 않는다.
4. 본체 발 앵커(96,160)를 공통 사용한다. 공격 자세는0~1 예고,2~3 발사,4~5 회복,6~7 돌진이다. 모든 공격에8장을 통째로 재생하지 않는다.
5. 보스는 정면이 보이는 한 방향 직교 뷰다.4방향 전용 몸체는 없다. 이동/조준은 논리 벡터로 처리하고 몸체를90도 회전하지 않는다. 투사체·직선 예고·잔상은 오른쪽이 기준이며 방향 회전 가능하다.
6. 기둥/문/보스 collider와 footprint는 실제 타일/플레이어 크기로 보정한다. 이미지 사각형 전체를 고체로 만들지 않는다. 아트 앵커와 데이터의 근사 collider는 별개다.
7. 입장과 귀환은 남쪽 문 하나를 공유한다. 닫힘·열리는 중·열림·잠금 상태 PNG가 있다. 전투 중 잠금, 토벌/보상 저장 후 열림으로 전환한다.
8. PNG 필터는 Nearest. 월드 VFX는 월드 카메라, HP/단계/보상 패널은 UI 뷰포트에서 그린다. 이름·단계번호·HP·보상명은 런타임 한글 텍스트다.

## 진행과 보상

처음에는1-1만 입장한다. 첫 토벌은1-2 진행 해금을 저장하지만1-2 구현 전에는 '해금·준비 중'으로 입장을 막는다. 이후 단계 보스/맵은 이 팩에 없다.

각 새 runId의 유효 토벌당 기존 LEGENDARY 풀에서1개를 본부 보관함에 지급한다.8칸 가방이 가득 차도 잃지 않는다. 클리어·다음 단계 진행·보상·수령 영수증을 함께 저장하고 같은run 중복 콜백/재시작/복귀로 추가 지급하지 않는다.

## 재사용 대상과 검증 한계

기존 연구소 벽/코너, 주인공, 아이템·등급 테두리, 메인 컴퓨터, Space 안내, 스킬 효과, 효과음은 실제 프로젝트에서 재사용한다. 이 팩에 해당 원본을 다시 넣지 않았다.

프레임/투명 가장자리·HP 프레임 중앙·JSON 이벤트 순서·광장 참조 동선·ZIP 무결성을 확인한다. 합성 예시와 GIF는 아트 확인 자료이며 실제 보스 AI·충돌·피해·저장·게임 실행을 검증한 화면은 아니다.
