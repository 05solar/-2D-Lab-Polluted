# 연구소 외벽·대문 V3

기존 연구소의 보라빛 금속·청록 조명 분위기에 맞춰 다시 그린 에셋입니다. PNG는 RGBA이며 게임에서는 Nearest 필터를 사용합니다.

## 파일

- `runtime/walls/exterior_wall_ring_768.png`: 전체 외벽 프레임. 중앙은 투명합니다.
- `runtime/walls/wall_north/south.png`: 각각 512×128인 가로 외벽 구간.
- `runtime/walls/wall_west/east.png`: 각각 128×512인 세로 외벽 구간.
- `runtime/walls/wall_corner_nw/ne/sw/se.png`: 각각 128×128인 외곽 모서리.
- `runtime/gate/main_gate_closed_512x256.png`: 대문 닫힘.
- `runtime/gate/main_gate_open_512x256.png`: 대문 열림. 중앙 통로는 투명합니다.
- `layout.json`: 분할 좌표, 크기, 기준점과 권장 배치 정보.
- `source/`: 고해상도 원본.

외벽은 지지대가 반복되는 기존 디자인 대신 연속적인 금속 벽면과 모서리 보강부로 구성했습니다. 이 팩의 벽 모듈은 외곽 직선·외측 모서리용이며 내벽의 T자/십자/안쪽 모서리 타일과 별도로 등록합니다.

## 게임 적용 기준

논리 타일이 64px일 때 외벽 두께는 128px(2타일), 대문 표시 크기는 512×256px(8×4타일)을 시작 기준으로 사용합니다. PNG 해상도만 높이고 기존 1타일 크기로 그리면 게임에서 커지지 않습니다. 게임 월드 단위로 환산한 실제 표시 크기와 충돌을 함께 갱신해야 합니다.

가로 외벽은 길이 방향으로만 늘리고 두께를 유지합니다. 세로 외벽도 길이 방향으로만 늘립니다. 모서리는 같은 두께로 배치합니다. 전체 프레임 이미지를 방 위에 통째로 덮으면 문이 막히므로 실제 문 개구부에서는 벽 구간을 분리합니다.

대문 닫힘/열림은 같은 표시 크기와 기준점을 사용합니다. `passageRectPx`는 투명 통행 영역 안의 배치 가이드입니다. 열린 상태에서는 해당 통로에 접근할 수 있고 문틀은 계속 충돌해야 합니다. 실제 세계의 벽 방향과 개구부 위치에 맞춰 충돌 좌표를 검증합니다. 닫힘/열림 애니메이션 프레임은 이번 팩에 포함되지 않습니다.

## 개발 AI 전달 문구

새 exterior_walls_gate_v3 팩을 등록하고 기존 연구소 외벽과 본부↔연구소 대문을 교체해라. layout.json을 참고해 외벽 두께 2타일, 대문 8×4타일의 실제 월드 표시 크기를 적용하라. 외벽은 구간과 모서리로 조립하고 대문 자리에는 실제 개구부를 만들어라. 닫힘/열림 이미지의 기준점을 일치시키고 문틀은 충돌, 열린 중앙 통로는 통행 가능하게 한다. 벽이 두꺼워진 만큼 가구의 벽 접촉 위치도 새 실내 면에 맞춰 갱신한다. 렌더 크기만 확대하고 충돌·가구 위치·길찾기는 이전 값을 남기지 마라. 변경한 게임을 새로 실행해 외벽 연결, 가구 밀착, 대문 통행의 일반/충돌 디버그 화면을 제공하라.
