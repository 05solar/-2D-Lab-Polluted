# 효과음 켜기/끄기 버튼

- 청록색 음파: 효과음 켜짐. 주황색 빗금: 효과음 꺼짐.
- runtime/에는 64·96·128px별 투명 PNG 두 상태와 96px 아틀라스가 있습니다.
- LibGDX에서는 Nearest 필터를 사용하고 현재 sfxEnabled 값에 따라 이미지와 툴팁을 바꿉니다. 버튼 클릭은 효과음 설정만 전환하고 배경음악은 유지합니다.
- 효과음을 끄면 재생 중인 효과음도 정지하고 이후 효과음 재생을 차단합니다. 배경음악의 Music 객체에는 영향을 주지 않습니다.
- 본부와 연구소에서 공유하는 설정을 사용하고 설정 저장이 있다면 함께 저장합니다. 클릭 영역은 보이는 버튼과 일치시킵니다.
- 실제 게임 코드는 이 팩에 포함되지 않습니다.
