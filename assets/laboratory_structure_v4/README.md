# 연구소 구조 통일 V4

기존 V3의 외벽 직선만 내부에 확대 적용하면서 생긴 접합부 혼용 문제를 해결하기 위한 팩입니다. 금속 표면 원화는 새로 제작했고, 벽의 연결 형상은 동일 규격으로 조립했습니다. 본 팩의 미리보기와 평면도는 에셋/설계 검증용이며 사용자의 실제 게임 실행 화면이 아닙니다.

## 좌표·크기 규약

- 아트 좌표와 JSON 사각형은 왼쪽 위 원점입니다. 게임 월드 좌표와 혼동하지 마세요.
- 벽 그림 128×128은 논리 셀 1개입니다. 논리 셀이 64px라면 0.5배로 그립니다. 외벽 2셀 두께는 벽 셀을 실제로 두 줄 배치해서 만듭니다. 큰 그림 한 장을 인접 바닥까지 늘려 그리지 않습니다.
- 벽 셀은 전체가 불투명하고 전체가 충돌 영역입니다. 실제 바닥인 투명 여백을 충돌로 잡는 문제를 피합니다.
- 47종은 8방향 이웃 연결입니다. N=1, NE=2, E=4, SE=8, S=16, SW=32, W=64, NW=128. 대각선은 양옆 직교 이웃이 모두 벽일 때만 유지합니다. 256가지 입력은 모두 정규화 후 47종 중 하나에 매핑됩니다.
- `turn_ne`는 N과 E 방향 벽과 연결된다는 뜻입니다. 방의 북동쪽 코너 위치를 뜻하지 않습니다. 자동 선택에는 파일 이름 대신 비트마스크를 사용합니다.
- 문 가로/세로는 벽이 뻗는 축입니다. 가로 문은 남북 통행, 세로 문은 동서 통행입니다. 문을 회전하거나 정면 그림으로 세로 문을 대신하지 않습니다.
- 방문은 권장 가로 4×1.5셀, 세로 1.5×4셀입니다. 이미지의 바닥 레일은 열린 상태에서 밟고 통과하는 문턱입니다. 문틀 양끝만 상시 충돌하며 닫힌 문짝은 추가 충돌합니다. JSON 충돌 사각형은 보수적인 통합 가이드이므로 실제 플레이어 크기에 맞춰 검증합니다.
- 본부↔연구소의 큰 대문은 기존 V3 닫힘/열림을 재사용합니다. V4 방문과 별도 역할입니다.

## 검증

`python3 verify_assets.py`: 47종 매핑, 256가지 상태 처리, 아틀라스 영역 일치, 벽 불투명 영역, 문 중앙 열림/닫힘 알파, PNG 재로딩 검사를 통과했습니다.

`python3 build_reference.py`: 참고 구조의 바닥 3,467셀 모두 입구에서 연결됨을 검사했습니다. 가구·몬스터 배치 후 연결성은 프로젝트에서 별도로 검증해야 합니다.

Java 예시는 이 환경에 javac가 없어 컴파일하지 못했습니다. 통합 프로젝트에서 실제 패키지를 추가하고 core:test/build로 확인해야 합니다. 사용자의 프로젝트 코드를 여기서 변경하거나 게임 실행을 검증하지는 않았습니다.

## 재생성

`source/`에 원본이 포함되어 있습니다. Pillow가 있는 Python에서 `build_assets.py`, `build_reference.py`, `verify_assets.py` 순으로 실행합니다. 재생성은 새 이미지 생성 요청 없이 포함된 원본을 사용합니다.
