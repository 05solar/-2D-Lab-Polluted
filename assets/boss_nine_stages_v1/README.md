# 9단계 보스 에셋 v1

8종 신규 보스(각 16프레임) + 기존 1-1 보스 재사용, 9종 실루엣/컬러 초상화, 신규 효과 12종(각 4프레임), 텍스트 없는 선택 카드, 기존 보스전 공용 바닥/기둥/문/HP바를 포함한다.

## 적용

1. BOSS_NINE_IMPLEMENTATION_PROMPT.md 전체를 구현 AI에 전달한다.
2. runtime/을 게임 에셋 경로로 복사하고 기존 GameAssets에 등록한다. source/는 원본 보관용이며 런타임 로딩 대상이 아니다.
3. animations.json의 셀/구간/앵커를 읽어 상태에 맞게 재생한다. 새 보스 시트는 1024×1024, 4×4, 256×256 셀이다. 번호는 위→아래, 왼쪽→오른쪽이다. LibGDX의 좌표/UV 방향은 어댑터에서 변환한다.
4. idle0~3, 예고4~5, 발동6~7, 회복8~9, 이동10~11, 사망12~15. 모든 프레임을 한 공격 애니메이션으로 재생하지 않는다. 각 보스는 한 방향 원화다. 90도 회전으로 다른 방향을 대체하지 않는다.
5. 새 보스 셀 [128,224]를 발밑 월드 위치에 붙인다. 프레임마다 trim/크기 변경 금지. 일반 보스 draw 8타일, 1-보스 9.5타일을 시작값으로 실제 게임에서 조정한다. 플레이어 스킬 범위는 현행 그대로 유지한다.
6. stage_catalog.json에서 카드별 실루엣/컬러 초상화와 보스를 매핑한다. 모든 잠금 카드에도 해당 실루엣이 보여야 한다. 잠금 표시는 별도 24px 배지다. 단계명/한글/숫자/버튼 글자는 코드로 표시한다.

## 데이터/시각 유의사항

- stage_catalog.json, patterns.draft.json, arena_layouts.json의 새 수치는 조정용 초안이다. 실제 기존 1-1 수치는 보존한다. integrationReady=false는 이 팩만으로 Java 기능이 완성되지 않았다는 의미다. 실제 연결과 검증 후에만 바꾼다.
- 신규 효과는 시각 자료다. 예고선·부채꼴·확장 고리·레이저의 정확한 판정은 코드/데이터로 그린다. 입자나 반투명 가장자리를 피해 반경으로 사용하지 않는다. 광역 표시 반경이 커져도 플레이어 스킬 반경은 변경하지 않는다.
- 기존 산성 투사체는 1-3의 투척에, 기존 충격/물웅덩이는 보조 효과로 재사용할 수 있다. 포탄은 기존 투사체+착탄 표시를 재사용한다. 전용 음원은 이 팩에 포함되지 않는다.
- preview/는 에셋을 조합한 예시이며 실제 게임 스크린샷이 아니다. scale_reference의 플레이어는 크기 비교용 표식이다.
- source/는 생성 원본이고 runtime/은 프레임 분리·고정 배율·투명 여백을 적용한 파일이다. 신규 몸체 전체 128프레임의 여백과 원본 바깥 경계 잘림을 검사했다.
- effects는 160×160 셀, 4열 한 줄 640×160이다. 몸체와 같은 atlas 크기로 자르지 않는다. 픽셀 필터는 기존 Nearest 사용.
- 실제 전투 코드/Gradle 테스트는 이 환경에 없으므로 수행하지 않았다. 검증 범위는 VALIDATION.json에 적혀 있다.
