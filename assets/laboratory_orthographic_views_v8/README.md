# 연구소 가구 정면·좌측면·우측면 V7

기존 V4/V5의 단순 이미지 회전본을 대체하는 24종 가구의 **정투영 3방향 에셋**입니다.

- `front`: 카메라가 앞면에 수직인 정면 모습
- `left_side`: 카메라가 왼쪽 면에 수직인 순수 좌측면 모습
- `right_side`: 카메라가 오른쪽 면에 수직인 순수 우측면 모습

측면은 정면 PNG를 회전하지 않고 별도로 그렸습니다. 측면에 앞면이나 윗면을 함께 보여 주는 3/4 시점은 포함하지 않습니다. 파일명 `left_side`와 `right_side`는 **카메라에서 보이는 물체의 면**을 뜻합니다.

## 구성

| 폴더 | 내용 |
|---|---|
| `runtime_256/` | 게임에 바로 쓰는 256×256 투명 PNG 72개 |
| `hires/` | 원본 디테일을 보존한 개별 투명 PNG 72개, 크기 가변 |
| `source_sheets/` | 재검수용 3방향 생성 시트 7장 |
| `preview_runtime_256.png` | 72개 에셋 전체 미리보기 |
| `QA_REPORT.md` | 잘림·방향·파일 검수 결과 |

게임 적용 시 투명 여백을 충돌 영역에 포함하지 말고, 별도의 바닥 점유 영역을 설정하세요. 픽셀 아트 필터는 LibGDX `Nearest`를 권장합니다. 이 팩은 정면·정측면 **입면도**이므로 90° 회전한 탑뷰 평면도와는 다릅니다.
