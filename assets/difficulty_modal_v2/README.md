# 난이도 선택창 V2

첨부 화면에서 선택 UI가 작고 오른쪽 아래에 큰 흰색 블록이 나타나는 문제를 확인하여 큰 패널 에셋을 새로 제작했습니다. 흰색 블록의 원인은 스크린샷만으로 확정할 수 없으므로 렌더링 코드 검증이 필요합니다.

- `runtime/difficulty_modal_960x640.png`: RGBA 960×640, 바깥쪽 투명. 게임 표시용.
- `source/difficulty_modal_source.png`: 고해상도 원본.
- `preview.png`: 진한 배경에서의 표시 미리보기.
- `layout.json`: 이미지 왼쪽 위 기준의 제목·세 선택 영역·하단 안내 영역.
- `FIX_PROMPT.md`: 기존 LibGDX 프로젝트의 UI 오류 진단 및 수정 지시문.

실제 글자, 호버/선택 상태, 클릭 영역은 코드에서 `layout.json`의 사각형과 동일하게 그립니다. PNG의 빈 영역에 한글을 추가로 생성하지 않습니다. 플레이 중 선택창은 화면 좌표계에서 화면 중앙에 그리고 창 크기에 맞춰 비율을 유지합니다.
