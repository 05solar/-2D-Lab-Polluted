# 본부 강화대·영구 강화 트리 에셋 v1

## 전달 파일

- `UPGRADE_IMPLEMENTATION_PROMPT.md`: 개발 AI에 그대로 전달할 구현 지시문.
- `runtime/`: 게임용 분리 투명 PNG 16개.
- `asset_catalog.json`: 파일별 크기와 강화대 앵커/충돌 시작값.
- `ui_layout.json`: 1120×720 기준 트리·상세창 배치 좌표(좌상단 원점).
- `data/upgrade_tree.example.json`: 9개 노드의 선행 관계·가격·효과 초안.
- `preview/`: 실제 PNG로 조합한 UI 예시와 전체 에셋 확인표.
- `source/`: 생성된 고해상도 원본.

## 적용

폴더를 프로젝트 `assets/ui/hq_upgrade_tree_v1/`에 복사하고 구현 프롬프트를 전달한다. GameAssets 단일 소유, Nearest 필터, 알파 블렌딩을 사용한다. 프레임 안에 아이콘을 40~44px로 배치한다.

모든 런타임 PNG에 글자와 비용은 없다. 영문 미리보기는 배치 설명이며 게임에서는 한글 폰트로 이름·비용·효과를 그린다. 기존 SPACE 안내와 HP HUD는 재사용한다.

가구 footprint는 픽셀 좌표의 조정 시작값이다. 실제 타일/캐릭터 크기에 맞춰 디버그 표시로 검증해야 한다. 왼쪽/오른쪽벽용 측면 가구는 이 팩에 포함하지 않는다.

## 제안 트리

- 체력: 최대 HP +20 → +30 → +50.
- 공격: 기본 공격력 +3 → +4 → +6.
- 스킬: 회복 해금 → 회복량 +10 / 추가 활성 슬롯 +1.

회복 기본값은 30 회복·10초 쿨다운이다. 비용은 확정값이 아닌 초안이다. 기존 밸런스가 있으면 그것을 우선한다. HP 강화 구매 시 현재 HP는 유지하고 최대치만 바뀐다.

이 결과물은 에셋과 구현 프롬프트다. 실제 게임 코드 적용, 스킬 실행, 저장 및 게임 실행 검증은 아직 수행하지 않았다.
