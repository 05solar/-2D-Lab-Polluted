# HQ Sales & Storage UI v1

오염 연구소 게임의 본부 자판기 판매 상점용 간단한 금속 UI 팩.

## 구성

- `runtime/`: 각각 분리된 투명 RGBA PNG 7개. 패널 960×640, 공용 버튼 256×64, 판매 표식 96×96, 재화 64×64/32×32, 슬롯/선택 테두리 64×64.
- `ui_layout.json`: 패널 기준 좌표와 버튼 상태 tint 예시. 좌상단 원점.
- `IMPLEMENTATION_PROMPT.md`: 개발 AI에 전달할 전체 구현 지시문.
- `preview/sale_ui_example.png`: 배치 예시. 빈 슬롯과 영문 문구는 미리보기 전용이며 실제 아이템/한글은 게임에서 렌더링한다.
- `source/`: 고해상도 생성 원본. 게임에는 `runtime`의 분리 PNG를 사용한다.
- `VALIDATION.json`: 이미지·레이아웃·압축 검증 결과.

## 사용

1. 이 폴더를 게임의 `assets/ui/hq_sales_storage_v1/`에 복사한다.
2. 개발 AI에게 `IMPLEMENTATION_PROMPT.md`와 에셋 폴더를 함께 제공한다.
3. 기존 자판기·물품·등급 테두리·SPACE 안내를 재사용한다.
4. PNG에는 글자가 없다. 버튼/한글/가격/수량은 런타임 텍스트다. 패널을 균일 배율로 확대/축소한다.
5. 슬롯의 가운데는 투명하다. 선택 테두리는 기존 등급 테두리를 가리지 않도록 바깥에 사용한다.

아트는 탁한 회색·보라색 금속과 절제된 청록 표시를 사용했다. 이전 게임 이미지 원본을 이 작업에서 직접 확인할 수 없어 색상과 스타일의 정확한 일치 여부는 실제 게임 화면에서 확인해야 한다.

이 패키지는 에셋과 구현 지시문이다. 게임 코드 적용·저장 기능 구현·실제 게임 실행 검증은 포함하지 않는다.
