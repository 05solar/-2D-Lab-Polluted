# 플레이어 체력 HUD · 8칸 가방 UI

기존 상점 UI의 자주색 금속·올리브색 천막·청록 조명 스타일에 맞춘 투명 PNG 에셋입니다.

## 포함 파일

| 파일 | 용도 |
|---|---|
| `runtime/hp_hud_frame_512x128.png` | 화면에 항상 보이는 체력 프레임과 빈 트랙 |
| `runtime/hp_fill_*_240x18.png` | 현재 HP 비율에 맞게 가로 폭을 조절하는 체력 채움 3색 |
| `runtime/backpack_open_empty_8slots_960x600.png` | R키로 열리는 가방 패널, 4열×2행 빈 슬롯 정확히 8개 |
| `runtime/backpack_shell_960x600.png` | 별도 슬롯 배치가 필요한 경우 사용할 빈 패널 |
| `runtime/slot_empty_108.png`, `runtime/slot_hover_108.png` | 개별 빈 슬롯·포커스 슬롯 |
| `runtime/r_backpack_prompt_128x64.png` | R키 가방 열기 힌트 |
| `preview/` | 완성 상태 미리보기 |
| `ui_layout.json` | 상대 좌표와 표시 규칙 |

## 게임 규칙

- 플레이어 최대 체력은 100입니다. 체력 숫자와 채움 폭은 실제 HP 상태에서 그립니다. 프레임 이미지에는 고정 수치를 넣지 않았습니다.
- 가방은 R키를 누를 때 열거나 닫습니다. 연구소에 한 번 들어갈 때 회수할 수 있는 물품은 최대 8개이며 각 물품은 한 칸을 차지합니다.
- 8칸이 꽉 차면 추가 회수 동작을 막고 `8 / 8`을 표시합니다. 본부 복귀 후 보관함에 회수품을 내려놓는 흐름으로 연결하면 다음 연구소 출입을 위한 8칸을 다시 사용할 수 있습니다.
- 슬롯 위의 아이템 아이콘은 `ui_layout.json`의 내부 72×72 영역에 별도로 렌더링합니다. 일반/에픽/레전드 등급 테두리는 슬롯 위에 색상 효과로 표시할 수 있습니다.

## LibGDX 적용

- `ScreenViewport` 또는 별도 UI `Stage`에 고정 배치하고 월드 카메라 이동과 분리합니다.
- HP 프레임을 먼저, 현재 체력 비율만큼 잘라낸 fill을 그 위에, 숫자를 마지막에 그립니다.
- `backpack_open_empty_8slots_960x600.png` 하나만 그리면 빈 슬롯 8개가 보입니다. 슬롯 8개를 추가로 그리면 중복됩니다.
- 작은 게임 화면에서는 패널을 뷰포트 너비·높이의 약 72% 이내로 비율 유지 축소합니다. R키 힌트는 패널을 닫은 상태에서 별도 표시할 수 있습니다.
- 픽셀 아트는 `TextureFilter.Nearest`를 사용합니다.

좌표는 `ui_layout.json`에 원본 PNG 기준, 왼쪽 위 원점으로 적었습니다. LibGDX 좌하단 원점에서 직접 그릴 때 Y좌표를 변환하십시오.
