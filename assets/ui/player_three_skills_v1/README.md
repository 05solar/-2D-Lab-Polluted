# 충격파·전기 투척·보호막 에셋 v1

게임용 아이콘3개와 VFX 시트6개, 판정 타임라인/강화 노드 초안, 개발 AI용 구현 프롬프트를 함께 제공한다.

## 파일

- `THREE_SKILLS_IMPLEMENTATION_PROMPT.md`: 기존 공통 스킬 시스템에 연결하는 상세 구현 지시문.
- `runtime/icons/`: 충격파·전기 투척·보호막 아이콘64×64.
- `runtime/vfx/`: 모든 프레임 셀128×128, 알파 투명 PNG 시트6개.
- `runtime/frames/`: 시트와 같은 고정 크기의 개별 프레임36개. 시트 대신 사용할 수 있다.
- `animations.json`: 프레임 수·순서·재생 구간·앵커·기준 방향·시각 범위.
- `data/skills.example.json`: 피해·반경·쿨다운·방어량·이벤트 시간 초안.
- `data/upgrade_nodes.example.json`: 스킬별 해금/강화6개 노드와 필요한 경우에만 추가할 슬롯 확장2개, 비용 초안.
- `preview/`: GIF, VFX 전체 예시, 각 시트의 번호 있는 프레임 확인표.
- `source/`: 이미지 생성 도구로 제작한 원본9개.

## 애니메이션 규격

| VFX | 프레임 | 시트 크기 | 재생 |
|---|---:|---|---|
| 충격파 | 8 | 512×256 | 15fps·1회 |
| 충격 피격 | 6 | 384×256 | 15fps·1회 |
| 전기 투사체 | 4 | 256×256 | 15fps·반복, 오른쪽이 기준 방향 |
| 전기 착탄/감전 | 6 | 384×256 | 착탄1회, 감전은 실제 상태 시간에 맞춰 별도 반복 |
| 보호막 생성/유지 | 6 | 384×256 | 0~1 생성 → 2~5 반복 |
| 보호막 파괴 | 6 | 384×256 | 15fps·1회 |

시트는 좌상단부터 행 우선이다. 모든 셀은128×128이며 프레임마다 trim/자동 확대하지 않는다. 기본 앵커는(64,64), 보호막/파괴는 발 기준(64,102) 시작값이다. 실제 캐릭터에 맞춰 두 보호막 효과의 크기·발 위치를 함께 보정한다.

## 초기 수치 초안

| 스킬 | 효과 | 쿨다운 |
|---|---|---:|
| 충격파 | 피해30, 반경2.5타일, 밀어내기0.8타일 | 6초 |
| 전기 투척 | 피해25, 속도10타일/초, 거리8타일, 감전0.5초 | 5초 |
| 보호막 | 피해60 흡수, 활성4초 | 12초 |

위 수치와 비용은 기존 게임의 확정값이 아니라 이번에 제안하는 초안이다. 기존 확정 설정이 있으면 우선하고 JSON에서 조정한다.

## 적용

폴더를 `assets/ui/player_three_skills_v1/`에 복사하고 프롬프트를 개발 AI에게 전달한다. 아이콘/시트는 단독 PNG로 사용할 수 있지만 실제 피해·충돌·감전·보호막 로직은 구현해야 한다.

돌진·회복의 기존 공통 스킬 모델과 슬롯/키캡/UI를 재사용한다. 새 슬롯이나 키를 이미지에 새겨 넣지 않는다. F/Q/R/H/Space 기존 입력을 유지하고 새 스킬은 사용자 등록 키로 발동한다.

충격파의 바깥 반경은 투명 셀의 절반이 아니라 실제 밝은 고리의 바깥 선이다. 최대 크기 프레임의 시각 범위를 JSON에 기록했으며 파티클까지 전부 피해 범위로 해석하지 않는다. 실제 월드에서 디버그 원/파면을 겹쳐 최종 보정한다.

보호막 유지 효과는 캐릭터가 보이도록 낮은 알파부터 조정한다. 보호막을 다 쓰면 파괴 시트, 시간 만료면 기존 버블을 코드로 페이드한다. 착탄6프레임과 실제 감전 지속 시간은 별개다.

PNG는 Nearest 필터·알파 블렌딩으로 그린다. GIF는 미리보기라 반복되지만 게임의 단발 효과는 반복하지 않는다. 효과음은 포함하지 않았으며 기존 사운드가 있으면 재사용한다.

## 확인 범위

이미지 디코딩, RGBA, 투명 가장자리, 고정 셀, JSON의 파일 경로·프레임 수·이벤트 시간, ZIP 무결성과 프레임 시각 확인을 수행한다. 실제 게임의 판정·쿨다운·강화·저장 구현이나 실행 테스트는 이 팩 제작에 포함하지 않는다. 미리보기는 실제 게임 캡처가 아니다.
