# 스킬 장착·단축키·회복 에셋 v1

## 전달 구성

- `SKILL_IMPLEMENTATION_PROMPT.md`: 개발 AI에 전달할 상세 지시문.
- `runtime/`: 투명 RGBA PNG 20개. 회복 아이콘, 12프레임 시트와 개별 프레임 12개, 일반/선택/잠금 슬롯, 빈 키캡, 공용 패널/등록 버튼.
- `heal_animation.json`: 프레임 순서, 재생 시간, 고정 발 앵커, 알파·렌더링 안내.
- `skill_defaults.example.json`: F 돌진 / Q 회복 / 1·2·3 추가 슬롯과 기본 스킬 수치.
- `ui_layout.json`: 장착 패널과 HUD 배치 시작값.
- `asset_catalog.json`, `VALIDATION.json`: 이미지 규격과 수행한 검증.
- `preview/`: 회복 GIF, 전체 프레임 확인표, 장착 UI 예시.
- `source/`: 이미지 생성 도구로 만든 고해상도 원본 3개.

## 회복 애니메이션

`heal_cast_sheet_512x384.png`: 4열×3행, 128×128 셀 12개, 좌상단부터 행 우선. 15fps, 0.8초, 게임에서는 1회만 재생한다. 발 앵커는 각 셀의 (64,108)이다. 개별 프레임을 써도 같은 좌표를 유지한다.

원본 셀을 같은 배율로 줄인 뒤 발밑 고리에 정렬하고 시작·종료 페이드를 적용했다. 프레임마다 크기를 바꾸거나 내용에 맞춰 잘라 쓰지 않는다. PNG 알파에 페이드가 포함돼 있다. JSON의 opacityEnvelope는 제작 기록이며 게임에서 중복 적용하지 않는다.

초록색 고리가 발밑에서 몸을 감싸 올라간다. 캐릭터 실루엣이 보이도록 기본 알파0.7부터 조정한다. GIF는 반복 확인용으로 끝에 잠깐 멈춘다. 게임은 JSON의 12프레임0.8초를 따른다.

## UI 적용

전체 폴더를 게임의 `assets/ui/player_skill_loadout_v1/`에 복사하고 프롬프트를 전달한다. PNG에는 키 글자·가격·쿨다운 숫자가 없다. 폰트/숫자/쿨다운 덮개는 게임 코드에서 그린다. 일반/선택/잠금 상태는 기존 판매·강화 팩의 프레임을 재사용했다.

새로 만든 것은 회복 아이콘·회복 효과·빈 키캡이다. 패널과 공용 버튼은 앞 단계 디자인을 재사용했다. 기존 키캡이 적합하면 기존 것을 계속 써도 된다. **기존 돌진 아이콘은 이 팩에 포함하지 않았다.** 실제 프로젝트의 돌진 아이콘을 재사용하도록 프롬프트에 명시했다. UI 예시의 DASH 글자는 해당 자리 설명이다.

초기 활성 슬롯 최소2개와 구매한 추가 슬롯 효과를 분리한다. 회복은 앞 단계 강화 해금과 연동하고 잠긴 스킬을 슬롯이 열렸다는 이유로 자동 해금하지 않는다. 재화·물품·강화 저장은 기존 프로필과 통합한다.

## 확인 범위

PNG 디코딩·RGBA·투명 가장자리·12프레임 크기와 고정 좌표·ZIP 무결성을 검사하고 프레임 확인표와 UI 배치를 눈으로 확인했다. 실제 캐릭터 크기에서의 연출, 입력, HP 회복, 저장은 게임 적용 후 확인해야 한다. 이 패키지는 실제 게임 코드를 수정하거나 실행한 결과가 아니다.
