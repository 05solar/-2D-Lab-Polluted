# Laboratory Tileset V2

기존 연구소 화면에서 나타난 반복 바닥, 끊긴 벽, 검은 문 공간 문제를 줄이기 위해 새로 제작한 64×64 전용 타일셋입니다.

## 구성

| 시트 | 크기 | 배열 | 용도 |
|---|---:|---:|---|
| `lab_floor_tiles_v2_64.png` | 384×256 | 6×4 | 기본 바닥·균열·수리·경고·해치 24종 |
| `lab_wall_autotiles_v2_64.png` | 256×256 | 4×4 | 직선·끝·안쪽/바깥쪽 모서리 16종 |
| `lab_structure_doors_v2_64.png` | 256×256 | 4×4 | T자·십자·문·문틀·파손 벽 16종 |
| `lab_overlay_decals_v2_64.png` | 384×256 | 6×4 | 오염·액체·균열·잔해·전선 오버레이 24종 |

모든 인덱스는 좌상단부터 가로 우선으로 증가합니다. 좌표는 `x = column × 64`, `y = row × 64`입니다.

## 렌더링 순서

1. `floor`
2. `overlay`
3. `wall`
4. `structure/door`
5. 가구·소품
6. 캐릭터

## 배치 원칙

- 기본 바닥은 `floor_clean_a/b/c`를 섞어서 사용합니다.
- 강한 균열·노출 배선·독성 액체는 전체 셀의 10% 이내로 제한합니다.
- 경고선은 장비 앞, 격리 구역 경계, 문 주변에만 사용합니다.
- 열린 문에는 별도의 검은 사각형을 그리지 않습니다.
- 벽 충돌은 이미지의 투명 여백이 아니라 논리 셀 또는 별도 충돌 사각형으로 관리합니다.
- 벽 모서리는 외곽과 내부를 구분해 선택합니다.
- 오버레이는 충돌을 만들지 않으며, 전기·독성 피해 여부만 별도 게임 규칙으로 결정합니다.
- LibGDX 필터는 `TextureFilter.Nearest`, 래핑은 `ClampToEdge`를 사용합니다.

전체 타일 설명은 `TILE_CATALOG.md`, 프로그램용 데이터는 `laboratory_tiles_v2.json`을 참고하세요.
