## 조작 키 (2026-10-20 공통 스킬 시스템 반영) [확정]
| 입력 | 동작 |
|---|---|
| WASD / 방향키 | 이동 |
| Shift | 달리기(팀장 소음 규칙 대상) |
| **마우스 왼쪽 클릭** | 공격(유일한 공격 입력 — 키보드 공격 키 없음) |
| F | **스킬 슬롯 1 기본 키**(최초 프로필 기본: 돌진) — 스킬창에서 변경 가능 |
| Q | **스킬 슬롯 2 기본 키**(최초 프로필 기본: 회복 — 해금 시) — 변경 가능 |
| 1 / 2 / 3 | **스킬 슬롯 3·4·5 기본 키**(기본 빈 슬롯) — 변경 가능 |
| R | 가방 열기/닫기 |
| **Space** | 상호작용 전용: 방문/대문 개폐, 상자·캐비넷 연타 개봉, 드롭 수집, 본부 자판기/정수기/강화 작업대/스킬 테이블 |
| D | 가방 가득 시 최저가치 교체 |
| **H** | **귀환 경로 토글(2026-10-20 재추가** — 미니맵 아래 버튼과 같은 동작, 엣지 1회) |
| Esc | 스킬창 키 등록 취소/패널 닫기 → 가방 닫기 → 일시정지 순 |
| 미니맵 아래 버튼 클릭 | 귀환 경로 토글(H와 동일) |
| HP 바 오른쪽 버튼 클릭 | 효과음+배경음악 세트 on/off |
| 오디오 토글 오른쪽 버튼 클릭 | **스킬창**(장착/키 등록) 열기 — 본부·연구소 공통 |
| 본부 스킬 테이블 SPACE | 스킬창 열기(북벽 금속 테이블 — 2026-10-20 침대 제거·버튼과 동일 창) |

- **예약 키**(스킬 키로 등록 불가): 이동(WASD/방향키)·Shift·Space·Esc·R·H·G·F1/F2/F12.
- 스킬 키 기본값 F/Q/1/2/3은 **최초 프로필에만** 적용되고, 이후에는 저장된 사용자 설정을 쓴다.
  같은 키를 두 슬롯에 등록할 수 없고, 키를 바꾸면 이전 키는 즉시 무효가 된다(새 키만 발동).
- UI 버튼(오디오 토글·스킬창·귀환 버튼)을 클릭한 프레임은 같은 클릭이 공격으로 처리되지 않는다.

## 난이도별 시드 기반 연구소 생성 (2026-10-20) [확정]
- **탐사 수명**: 본부 남쪽 대문 → 난이도 선택 "확정"이 곧 새 탐사이며 그때만 새 64비트 시드로
  맵을 생성한다. 선택창만 열거나 창 크기 변경/일시정지/연구소 화면 재생성으로는 맵이 바뀌지
  않는다(같은 세션 안에서 laboratory 스냅샷 유지). 같은 seed+generatorVersion+난이도 = 같은 맵.
- **규모**: 쉬움 128×96·16방 / 보통 160×120·25방 / 어려움 192×144·36방, 난이도별 구조 틀 4종
  (compact/courtyard/staggered/twin_wings). 방 크기·모양(모서리 후퇴)·연결·테마·가구 변형·캐비넷·
  몬스터가 시드로 달라진다(모든 입장이 반드시 다른 맵이라고 보장하지는 않는다).
- **품질 공통 기준**: 기존 쉬움 맵의 V4 벽/문(5칸 직선 지지), 방향별 가구 뷰(북=정면/남=뒷모습/
  동서=측면, 회전 금지), 컨테이너 가중 배치(벽/구석/가구옆/중앙)·접근 지점 보장, 2타일 외벽 링+
  남쪽 대문 1개(본부↔연구소 동일 출구)를 모든 난이도에 적용. 인접 방 사이 짧은 도그레그 복도
  (평균 6~7타일), 테마 16종 전부 등장(보통/어려움은 반복 증가).
- **몬스터**: 쉬움은 경비원·팀장 **금지**(슬라임 75%/연구원 25%, 총 56 = 현재 검증 예산 — 8배
  재적용 없음). 보통 88/어려움 126(방 수 비례), 경비원·팀장 가중 증가+최소 1. 팀장은 두 벽이
  만나는 유효 구석 후보에만 소환(부족 시 목표 축소·기록 — 중앙 후보 대체 금지). 분노·감지·추격
  AI 규칙은 기존 그대로(구석은 소환 위치일 뿐 추격을 막지 않는다).
- **접근성 보증**: 대문 앞 스폰에서 모든 방 활동 영역·모든 캐비넷의 상호작용/드롭 지점·문 양방향
  접근이 실제 배우 몸체 그리드(가구/컨테이너 포함, 대각 끼어들기 없음)로 검증된다. 실패 시 해당
  배치 수리 → attempt 하위 시드 3회 → 검증된 폴백(쉬움=기존 수제 캠퍼스) 순. 무한 재생성 금지.
- **재현/디버그**: 입장 로그 "LabGen generatorVersion=.. templateVersion=.. difficulty=.. seed=..
  generationSeed=.. templateId=.. contentHash=.. fallbackUsed=.."가 버그 재현 정보다.
  `LAB_SEED=<64비트 정수>`로 시드 고정, `LAB_CLASSIC_MAP=1`로 기존 수제 맵 강제(회귀 기준).
- **진행 중 탐사 저장**: 기존 세이브는 탐사 중단 복원을 지원하지 않는다(이번 단계 범위 밖 —
  본부 영구 프로필만 보존). 앱 종료 시 진행 중 탐사는 소멸하고 다음 입장은 새 탐사다.

## 9단계 보스전 (2026-10-21) [확정]
- **단계 사슬**: 1-1 폐기물 변이체(레거시 C-01 유지) → 1-2 냉각관 거수 → 1-3 배양낭 군체 →
  1-4 보안 제압 기체 → 1-5 신경 접속 표본 → 1-보스 중앙 격리실 융합체 → 2-1 저온실 다족
  실험체 → 2-2 변이 식물 실험체 → 2-3 이동형 배양 탱크. 이전 단계 토벌이 다음 단계를 해금

  존재. 단계 ID·저장 키는 1-1 팩과 동일 — 기존 세이브(1-1 클리어·1-2 해금·영수증)는
  마이그레이션 없이 그대로 동작. 디버그 전체 해금(LAB_BOSS_UNLOCK_ALL=1)은 릴리스 진행과 분리.

  신규 수치는 초안 — 게임 조정 전제). 렌더러는 상태를 그리기만 하고 피해·보상을 실행하지 않는다.

  피격 박스(중심=발+1.6타일)·이동 충돌 footprint·패턴 사거리는 서로 다른 데이터. 근접 적중 =
  공격 판정 도형과 피격 박스의 겹침. **플레이어 스킬 수치는 변경 금지** — 기준값은
  PlayerSkillRangeBaselineTest로 고정(근접 0.9 / 돌진 3·0.18s·쿨3 / 충격파 2.5·0.8 /
  전기 10·8·0.18·기절 0.5 / 보호막 60·4s).
- **애니메이션**: 정면 시트 1종을 상태 세그먼트로만 재생 — idle 0-3 / 예고 4-5 / 발사 6-7 /

  취소, 동시 사망 실패 우선, 장판류는 maxZones 상한 + `boss_toxin` 공유 틱 그룹(겹쳐도

- **패턴**(한 번에 하나, 예고→활성→회복; 초기 투척→장판→돌진 1회씩 후 시드 가중 선택·즉시
  반복 금지, 패턴 사이 0.6초):
  - 시약 투척: 예고 0.8초(발사선 표시), 0.5초에 조준 고정(이후 추적 없음), 0.8/0.95/1.1초에
    ±18°/0° 3발(피해 20, 6.5타일/s, 18타일, 반경 0.18). swept 충돌 — 기둥/벽/닫힌 문이 먼저면
    착탄만(뒤 플레이어 무피해), 수명 종료는 무피해 소멸. 장판을 남기지 않는다.
  - 오염 장판: 시전 시작에 플레이어 바닥 고정(벽/기둥 안이면 가장 가까운 유효 바닥으로
    결정론 보정), 반경 2.2 원형 예고 1초(마지막 2/15초에 생성 프레임 — 무피해), 1초에 활성 —
    완성 크기·피해 동시 시작, 4초 유지, 0.5초 틱 피해 8(활성 첫 틱 허용, 경계 재진입 연타
    없음). 최대 2개, 겹침은 플레이어당 공통 틱 1회. 낙하식 — 기둥 뒤 비차폐, 기둥 footprint
    제외, 통행 불가 셀에 미배치. 만료/보스 사망 즉시 판정 해제.
  - 장비 돌진: 예고 0.9초(직선 경로 폭 = collider 1.8+여유), 0.55초 조준 고정, 9타일/s·최대
    8타일. 벽/기둥/닫힌 문 표면 앞 즉시 정지(기둥 파괴/관통/순간이동 없음) → 회복 0.9초(공격
    기회). 실제 돌진 구간 교차에만 1돌진 1회 피해 30(정지/회복 중 겹침 무피해).
- **피해/저항**: 플레이어 피해는 기존 보호막→HP 공통 파이프라인 1회(무적 규칙 유지). 보스는
  공통 전투 모델로 피격·사망(사망 임계 1회 전이, 사망 6프레임 1회 후 마지막 유지). 저항은
  JSON: 넉백·경직(감전 행동 중단) 면역, 전기 직접 피해는 받음 — 감전 표시만 나온다.
- **보상**: 유효 토벌 1회 = 기존 LEGENDARY 카탈로그(loot_tables.json) 가중 추첨 1개,
  **runId 파생 시드로 고정**(결과창 재진입/저장 재시도/재실행에도 같은 아이템, 중복 지급 없음).
  가방 8칸과 무관하게 **본부 보관함 지급**(삭제/자동 판매/바닥 방치 없음). 토벌 기록+1-2 진행
  해금+아이템 인스턴스+영수증("stageId#runId")을 하나의 프로필로 원자 저장 — 실패 시
  REWARD_PENDING 유지·같은 보상으로 재시도, 성공 후에만 CLEARED·귀환문 개방.
- **실패**: 보상·해금 없음. 결과창에서 재도전(새 runId — 현재 최대 HP로 회복) 또는 본부 복귀
  (소지품·영구 진행 보존 — 일반 연구소의 사망 물품 상실 규칙은 보스 모드에 적용되지 않는다).
- **복귀**: 결과창 버튼 또는 열린 귀환문 남쪽 통과(0.35초 페이드 재사용, 1회만). 미구현 1-2로
  자동 진입하지 않는다. 디버그: LAB_START_BOSS=1(직행), LAB_BOSS_SEED(패턴 시드 고정),
  LAB_BOSS_AUTO=win|fail(자동 검증).

## 전투 판정 [확정]
- 한 번 생성된 공격은 **같은 대상을 한 번만** 타격한다.
- HP는 0보다 작아지지 않는다.
- 사망 상태의 대상은 추가 피해를 받지 않는다.
- 몬스터와 접촉했다는 이유만으로 매 프레임 피해를 주지 않는다.
- 공격 쿨다운·피격 무적 시간은 **초 단위**로 관리한다.
- 실제 공격 동작과 명중 구간이 일치해야 한다.

## 이동·소음 [확정]
- 이동 거리 = `speed * delta` (프레임 속도와 무관, 단위 테스트로 검증).
- 대각선 이동은 방향 벡터를 정규화해 등속을 유지한다.
- 달리기 횟수는 `WALKING → RUNNING` **전환 순간에만** 증가한다.
- 키를 계속 누르는 행위를 여러 번의 달리기로 세지 않는다.
- 월드 단위: 1 타일 = 1 단위. 걷기/뛰기 속도 기본값은 [임시값](`BalanceConfig`).

### 달리기 시작(RunStarted)의 정의 [확정 / 운영 정의 일부 임시]
- 이동 상태가 `WALKING`(또는 정지)에서 `RUNNING`으로 바뀌는 그 프레임 1회.
- 달리는 동안에는 프레임마다 세지 않는다.
- **RUNNING 성립 조건(운영 정의):** "달리기 입력(RUN) + 실제 이동 중"일 때만 RUNNING.
  제자리에서 RUN만 누르면 WALKING으로 보고, 움직이기 시작하는 프레임에 RUNNING 전환 = 달리기 시작.
  (구현: `RunStartDetector`. 단위 테스트로 1회성/재시작 2회성 검증)

## 몬스터 행동 상태 기계 (2026-10-16 개편) [확정]

상태: `IDLE(대기)` ↔ `WANDER(배회/순찰)` → `CHASE(추적)` → `ATTACK` / `SEARCH(마지막 목격 지점 탐색)`
→ `RETURN(활동 구역 복귀)`.

### 발견(탐지)
- 발견 = **발견 거리 안 + 시야가 닿을 때**만. 종류별 발견 거리: 슬라임 4 / 연구원 5 / 경비원 7(≈기준 5타일,
  `*DetectionRadius`). **벽과 닫힌 문은 시야를 차단**한다(`LaboratoryRoom.sightBlocked`) — 가까워도 벽 뒤
  플레이어를 거리만으로 발견하지 않는다. 열린 문·통로로 보이면 발견한다. 가구·몸체는 시야를 막지 않는다.
- 감지·경로 재평가는 매 프레임이 아니라 개체 id로 분산된 주기(`monsterSenseIntervalSeconds` 0.15s)로만
  수행한다(EASY 8배 성능).

### 추적과 해제 (히스테리시스)
- 추적 중 플레이어가 보이면 **마지막 목격 위치**를 갱신한다. 시야를 잃으면 그 기억 지점으로만 이동하며,
  벽 너머의 현재 위치를 계속 알아내지 않는다.
- 해제 조건(하나라도 만족 시): ① 거리 > `monsterChaseReleaseRadius`(8타일 — 발견 거리보다 커서 경계에서
  상태가 반복 전환되지 않음) ② 시야 상실 상태가 `monsterLostSightGraceSeconds`(2초) 초과
  ③ 활동 구역(스폰 지점)에서 `monsterHomeLeashRadius`(12타일) 초과 이탈.
- 해제 후: 시야 상실로 끝났으면 마지막 목격 지점 주변을 `monsterSearchMin~MaxSeconds`(2~4초) **탐색(SEARCH)**,
  거리·구역 이탈로 끝났으면 **복귀(RETURN)**. 복귀는 걸어서 하며(순간이동·스폰 좌표 집결 금지), 복귀 중에도
  탐지 조건을 다시 만족하면 재발견한다. 해제로 HP 회복·재생성 같은 부수 효과는 없다.
- 공격 사거리 안에서는 플레이어 중심까지 파고들지 않고 멈춰서 공격 기회를 기다린다.

### 배회(종류별 리듬)
- 공통: 목표 지점으로 1~3타일 걷고 0.5~2초쯤 쉰다. 매 프레임 방향을 바꾸지 않고 도착·막힘·시간 경과에만
  다음 목표를 고른다. 목표는 현재 위치에서 시야가 닿는(같은 방/열린 문 너머) 통행 가능 칸이라 벽·가구
  안에 생기지 않으며, 활동 구역(12타일) 안으로 제한된다. 휴식 시간·출발 시점은 개체마다 다르다.
- **슬라임**: 짧게(1~2타일) 이동하고 자주(0.8~2초) 멈춘다.
- **경비원**: 홈 주변 반경 4타일에서 고른 2~3개 순찰 지점을 오가며 짧게(0.5~1초) 대기한다.
- **연구원**: 장비(홈) 주변 2타일 안을 짧게 배회하고 상대적으로 길게(1.5~3초) 대기한다.
- **팀장**: 평소 구석에 머무르고(배회 없음), 근접 발견 규칙을 쓰지 않는다. 주변 달리기 시작 2회로만
  분노한다(기존 규칙). 분노 후 추적은 위 해제 규칙(거리·시야·활동 범위)을 따르며, 해제되면 원래 구석으로
  걸어서 복귀하고 **복귀 완료 시 분노·소음 누적이 초기화**된다(이후 다시 2회 규칙으로 분노 가능).

### 다수 몬스터 이동
- 이동 시 주변 0.9타일 안 몬스터와 **약한 간격 유지(분리)**를 방향에만 섞는다 — 벽 충돌·통로 이동이 항상
  우선이라 좁은 문 앞에서 서로 밀어내며 영구 정지하지 않는다.
- F1 디버그: 몬스터별 상태 텍스트, 발견 반경(청록/주황)·해제 반경(회색) 원, 현재 목표(흰 선)·마지막 목격
  지점(보라 선) 표식.

## 팀장(TeamLeader) 규칙 [확정]
- 지정 자리에 **앉은(SEATED) 상태**로 시작한다.
- 주변에서 플레이어가 **걷기만** 하면 반응하지 않는다.
- 감지 범위(hearingRadius, [임시값]) 안에서 **달리기 시작 이벤트를 2회** 감지하면 분노한다.
  - `monster.teamLeader.runTriggerCount = 2` [확정]
- 한 번의 달리기 시작은 한 번만 계산한다.
- 플레이어에게 **직접 공격받으면 즉시 분노**한다.
- 분노 후 추격·공격한다. 공격 1회는 플레이어 HP를 **35** 감소시킨다.
- 상태 흐름: `SEATED → WARNED → ENRAGED → CHASE → ATTACK → RECOVER`(→ `DEAD`)

## 보물 반납 [확정]
반납은 다음을 **모두** 만족할 때만 성공한다.
1. 플레이어가 보물을 운반 중이다.
2. 플레이어가 본부 반납 영역(DELIVERY_ZONE) 안에 있다.
3. 상호작용 입력이 **새로** 발생했다(pressed).
4. 같은 보물이 아직 반납되지 않았다.

## 배경 타일 충돌·의미 [확정(충돌) / 임시(위험 효과)]
- **벽**: 고체. **닫힌 문**: 상호작용 기능 전까지 벽과 동일하게 충돌한다.
- **열린 출입구**: 통과 가능.
- **장식 바닥**(균열·얼룩·경고): 통과 가능. 이동/충돌에 영향을 주지 않는다.
- **위험 바닥**(독성·전선): 통과 가능하며 `hazard`로 데이터 구분만 한다.
  HP 감소·상태 이상 등 실제 피해 효과는 아직 없다(2단계 전투 이후 별도 구현).
- 벽의 시각 방향(북/남/동/서/모서리)은 이웃을 보고 자동 선택하지만, **충돌은 논리 벽 셀 기준**이라
  시각이 바뀌어도 통과 가능 여부는 변하지 않는다.

## 사망·보상 [확정] (2026-10-15 재소환 구현)
- 사망 시 이번 탐사의 **미반납** 보물 보상은 제거된다 — 구현: 사망 시 가방(8칸) 소지품을 **모두 잃는다**.
- 이미 반납 완료한 보상(재화)과 진행 플래그는 다음 탐사에도 유지된다.
- **본부 재소환**: 쓰러짐 연출을 포함해 `deathRespawnDelaySeconds`(기본 2초) 뒤 소지품을 비우고
  페이드와 함께 본부 스폰으로 이동, 도착 시점에 부활(HP 최대)한다. 재소환은 사망 1회당 1회만 요청되고,
  사망 상태 동안의 늦은 처치 보상 등으로는 회복/부활하지 않는다(부활은 재소환 경로 전용 `Player.revive`).
- 연구소 상태(열린 상자·남은 몬스터)는 일반 복귀와 동일하게 유지된다.

## Laboratory Tileset V2 — 충돌·위험 규칙 [확정]

- 충돌은 **논리 셀(TileType) 또는 벽 충돌 사각형** 기준이며, 타일 이미지의 투명 여백을 충돌로 쓰지 않는다.
  - 기본 바닥/장식 오버레이: 통과 가능. 벽/닫힌 문: 통과 불가. 열린 문/출입구: 통과 가능.
  - `wall_breach_*`(파손 벽)는 지름길로 쓸 때만 충돌 해제(기본은 충돌). 가구는 별도 충돌 영역.
- 위험(hazard)은 **시각과 분리**된 데이터다(`Hazard`): 독성 계열(toxic/contamination) → TOXIC,
  전기 스파크 → SHOCK. 전선(cable/exposed_wires) 자체는 hazard가 아니다. 1단계는 의미만, 피해 로직은 이후.
- 문 방향은 벽 방향과 일치: 가로 벽=가로 문, 세로 벽=세로 문. 문 상태 변경 시 논리 충돌과 시각이 함께 바뀐다.
  문 타일은 벽 오토타일보다 우선(벽이 문을 덮어쓰지 않음). 열린 문에는 검은 void 대신 문턱/바닥이 보인다.
- 바닥 변형은 고정 seed(`FloorVariantResolver.DEFAULT_SEED=20261007`)로 결정 → 실행마다 동일.
  같은 바닥 타일이 가로·세로 3개 이상 연속되지 않는다. 경고선은 장비 앞/격리 경계/문 주변에만, 사각형 반복 금지.

## Door assembly and collision (2026-10-07)

A door needs a straight wall run of at least five cells. Its center occupies one cell and its two neighboring wall cells become jambs. A corner, junction, adjacent door, or missing jamb space rejects the placement. The surrounding wall topology determines horizontal or vertical direction; the map character only chooses initial open or closed state. `CLOSED`, `OPENING`, and `CLOSING` block movement; only `OPEN` is passable. State changes keep the same cell and direction, and visual art follows collision from the same door object. The opening shows the underlying floor and threshold.

## 임시 본부 천막 [현재 구현 / 임시 전환 시간]

- 본부는 연구소와 분리된 안전 구역이며 몬스터를 생성하지 않는다. 외벽, 모래주머니, 큰 가구의 바닥 접촉부는 충돌한다. 열린 남쪽 천막 출입구와 매트는 통과할 수 있다.

  장착·중복/예약 키)은 로드 시 정리하고 이유를 로그로 남긴다 — 해금 기록은 지우지 않는다.

## 추가 스킬 3종 — 충격파·전기 투척·보호막 (2026-10-20) [확정]

공통 규칙: 해금(강화대) → 스킬창 장착 → 등록 키 발동. 생존·해금·장착·쿨다운·입력 허용 검증 후
**시전 시작 성공 시 쿨다운을 1회 시작**한다. 준비 중 사망/맵 전환은 미발생 효과만 취소(쿨다운
유지), 시작 실패(잠김/쿨다운/보호막 활성 중 재시전 등)는 아무것도 소모하지 않는다. 일시정지는
시전·쿨다운·투사체·감전·보호막 시간·VFX를 함께 멈춘다. 수치 유일 출처:
`assets/ui/player_three_skills_v1/data/skills.json`(2026-10-20 동봉 초안 채택 — 거리 단위는 월드
타일). 판정 타임라인은 시뮬레이션 누적 시간 기준이고 이벤트 경계는 "이전 < t ≤ 현재"(t=0은 시작
시 1회, 프레임 드롭 시 건너뛴 경계 전부 순서대로), 시각 프레임도 같은 elapsed로 고른다.
진행 중 충격파/투사체/보호막은 맵 이탈·사망 시 제거되고(세이브에 저장하지 않음), 쿨다운 스냅샷은
기존 정책대로 보존된다. 처치 시 회복(+20)·HIT/DEAD 전환·타격음은 일반 공격과 **같은 타격
경로**(applyPlayerSkillStrike)를 쓰되 피해는 스킬 고정값+전용 강화(기본 공격 보너스 중복 가산 없음).

### 충격파 (기본 슬롯 3·키 1)
- 피해 30(+강화 10), 최대 반경 2.5타일, 밀어내기 0.8타일, 쿨다운 6초.
- 원점은 **시전 시작 위치에 고정** — 발동 후 이동해도 충격파가 따라가지 않는다.
- 8프레임/15fps: 0번 중심 예고(무피해), 1/15초부터 피해 활성, 4/15초 최대 반경, 5/15초 피해
  종료, 이후 잔상(재타격 없음). 판정 파면은 radiusCurve × 최대 반경 — 시작부터 원 전체를 때리지
  않는다. 렌더 링은 visualExtent 보정으로 판정 파면과 같은 속도.
- 명중: 직전→현재 파면 사이 고리와 hurtbox가 교차한 최초 시점에 시전(castId)·대상별 **1회**
  피해+원점 바깥 방향 밀어내기(같은 위치면 안정 폴백 방향 — NaN 금지). 원점 위 대상도 첫 활성
  구간에 포함되고, 이동하는 적·큰 delta로 파면을 건너는 경우도 고리 검사로 걸린다.
- 벽·닫힌 문·solid 가구 뒤는 원점→대상 경로 차폐 검사로 맞지 않는다(장식 오버레이는 차폐 아님).
  밀어내기는 기존 이동/충돌 해석을 통과해 벽·문·가구를 관통하지 않는다.

### 전기 투척 (기본 슬롯 4·키 2)
- 직접 피해 25(+강화 10), 속도 10타일/초, 최대 8타일, 충돌 반경 0.18, 감전 0.5초, 쿨다운 5초.
  관통·연쇄·광역 없음.
- 방향은 **시전 시작에 확정**(이동 입력 → 없으면 바라보는 방향) — 비행 중 유도되지 않는다.
  (기존 조준 시스템이 바라봄/이동 입력뿐이라 마우스 조준은 쓰지 않는다.)
- 준비 2/15초 뒤 투사체 1회 생성(이벤트 시점의 플레이어 위치, 준비 중 피해 없음). 아트 기준
  방향 +X를 이동 각도로 회전해 그린다(비행 4프레임 반복).
- 이동은 swept(샘플 간격 ≤ 충돌 반경) — 큰 delta에도 얇은 벽을 통과하지 않고, 같은 구간에서
  벽이 몬스터보다 앞이면 벽 착탄만(벽 뒤 몬스터 무피해). 몬스터 첫 충돌이면 피해+감전 1회 적용
  후 소멸, 착탄 VFX는 충돌 표면에서 즉시. 최대 사거리 도달은 피해·착탄 없이 소멸.
- **감전**: 남은 시간 동안 몬스터의 자율 이동·새 공격 시작을 막고, 아직 타격이 확정되지 않은
  공격은 취소한다(이미 들어간 피해는 유지). 넉백 물리는 그대로. 재적용은 max(남은, 새) 갱신으로
  무한 중첩이 없고, 종료 시 자연 복귀한다. 감전 오버레이는 실제 남은 시간 동안만(착탄 1회 연출과
  별개).

### 보호막 (기본 슬롯 5·키 3)
- 흡수 60(+강화 30), 활성 지속 4초, 쿨다운 12초. 준비 2/15초 뒤 방어 시작(생성 0~1프레임 —
  준비 중에는 막지 않는다), 이후 2~5프레임 반복(알파 0.65, 캐릭터 가독). 플레이어를 따라다니며
  별도 충돌체가 아니다.
- 피해 처리는 **기존 공통 파이프라인 한 곳**: 무적 검증 → 보호막 흡수 → 남은 피해만 HP 차감 →
  피격/사망. 예: 보호막 20/피해 35 → 보호막 0 + HP −15. 전부 흡수하면 HP 그대로(피격 무적은
  기존 규칙대로 시작 — 겹친 적이 프레임마다 깎지 못함). 무적 거절 공격은 보호막도 깎지 않는다.
- 흡수량 0 = 그 사건에서 방어 종료+**파괴 연출 1회**(잔여 피해는 같은 사건에서 처리, 추가 피해
  이벤트 없음). 지속 만료 = 파괴와 구분된 **알파 페이드**(깨지는 연출 없음). 큰 delta가 만료를
  통과하면 만료를 먼저 처리해 그 뒤 피해를 흡수하지 않는다.
- 활성(준비 포함) 중 재시전은 실패 — 쿨다운/흡수량을 재설정하지 않고 중복 버블도 없다.
  사망/맵 이탈 시 보호막·VFX 정리(사용한 쿨다운은 유지), 슬롯 해제는 복제/재충전하지 않는다.
