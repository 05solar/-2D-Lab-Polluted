# GAME_DESIGN — 폐쇄 연구소 보물 회수 게임

> 상태 표기: **[확정]** 규칙서로 확정 · **[제안]** 방향만 정함 · **[미정]** 아직 안 정함
> (2026-10-23 갱신 — 구현 수치·세부 규칙은 `GAME_RULES.md`, 현황은 `PROGRESS.md`)

## 핵심 목표 [확정]
플레이어가 폐쇄된 오염 연구소를 탐사하며 몬스터를 처치하거나 피하고, 컨테이너의 물품을
회수해 임시 본부로 가져와 보상을 확정한다. 보상(재화)으로 능력을 영구 강화해 더 위험한
구역·보스에 도전한다.

핵심 재미는 전투뿐 아니라 **소음 관리 · 전리품 운반 · 귀환 시점 판단**에 있다.

## 게임 루프 [확정 — 구현됨]
1. 임시 본부(14×10 안전 구역)에서 준비: 스킬 장착/단축키(스킬 테이블), 영구 강화(작업대),
   물품 판매(자판기), 보스 단계 선택(메인 컴퓨터), HP 회복(물통).
2. 남쪽 대문 → 난이도 선택(쉬움/보통/어려움) → 시드 생성 연구소 입장.
3. 걷기/뛰기 구분 이동(뛰기 소음은 팀장 분노 유발). 몬스터 4종과 전투하거나 회피.
4. 컨테이너(E 연타 개봉)에서 물품 회수 → 8칸 가방(가득 차면 D로 최저가치 교체).
5. 남쪽 대문으로 귀환 → 가방이 본부 보관함으로 이관 → 선택 판매로 재화 확정.
6. 사망 시 이번 탐사의 미반납 물품 손실 → 본부 재소환(영구 진행은 보존).
7. 별도 축: 메인 컴퓨터 → 보스 9단계 순차 공략 → 유효 토벌당 전설 물품 1개(보관함 지급).

## 조작법 [확정]
`GameAction`으로 관리, 실제 키는 `KeyBindings`. 스킬 키는 스킬창에서 변경 가능(예약 키 제외).

| 액션 | 기본 키 | 비고 |
|------|------|------|
| 이동 | 방향키 / WASD | held |
| 달리기 | Shift | held — 시작 순간이 소음 |
| 공격 | 마우스 좌클릭 | 전용(키보드 공격 없음) |
| 상호작용(문/상자/가구/대문) | Space | pressed |
| 스킬 슬롯 1~5 | F / Q / 1 / 2 / 3 | 기본값 — 변경 가능 |
| 가방 | R | 열기/닫기 |
| 귀환 경로 토글 | H | 미니맵 아래 버튼과 동일 |
| 일시정지/패널 닫기 | Esc | 스킬창→가방→일시정지 순 |

## 맵과 구역 [확정 — 구현됨]
- **임시 본부**: 고정 14×10. 상호작용 5종(자판기/물통/강화 작업대/스킬 테이블/메인 컴퓨터).
- **폐쇄 연구소**: 난이도 확정마다 64비트 시드로 생성 — 쉬움 128×96·16방 /
  보통 160×120·25방 / 어려움 192×144·36방, 테마 방 16종, 남쪽 대문 왕복.
- **보스 투기장**: 단계별 전용 광장(36×28~52×40) — 일반 탐사와 분리된 모드.

## 몬스터 역할 [확정]
| 몬스터 | 역할 |
|--------|------|
| 슬라임 | 약한 일반 몬스터 |
| 경비원 | 순찰·추격(쉬움 맵에는 없음) |
| 연구원 | 장비 주변 배회 |
| 팀장 | 소음 반응 엘리트. 구석 착석, 달리기 소음 2회 또는 피격 시 분노 |

보스 9종(1-1 폐기물 변이체 ~ 2-3 이동형 배양 탱크)은 별도 패턴 전투 — `GAME_RULES.md` 참고.

## 성장 [확정 — 구현됨]
- 판매 재화로 영구 강화 트리 구매(체력/공격/스킬 17노드, 원자 저장).
- 스킬 5종(돌진·회복·충격파·전기 투척·보호막) 해금→장착→단축키, 활성 슬롯 2→최대 5 확장.
- 보스 유효 토벌당 전설 등급 물품 1개(runId 영수증 — 중복 지급 없음).

## 성공·실패 조건 [확정: 탐사 단위 / 미정: 최종 목표]
- 성공: 전리품 반납으로 재화 누적 → 강화 → 더 어려운 난이도·다음 보스 단계.
- 실패: HP 0 → 이번 탐사 미반납 물품 손실(영구 진행·보관함은 보존). 보스전 실패는
  보상·해금 없음(재도전 가능).
- 최종 클리어 조건: [미정] — 현재 콘텐츠 끝은 보스 2-3 토벌.
