# GAME_DESIGN — 폐쇄 연구소 보물 회수 게임

> 상태 표기: **[확정]** 규칙서로 확정 · **[제안]** 방향만 정함 · **[미정]** 아직 안 정함

## 핵심 목표 [확정]
플레이어가 폐쇄된 연구소를 탐사하며 몬스터를 처치하거나 피하고, 보물함을 찾아
임시 본부로 운반해 보상을 확정한다. 보상으로 능력을 강화해 더 위험한 구역을 탐사한다.

핵심 재미는 전투뿐 아니라 **소음 관리 · 보물 운반 · 귀환 시점 판단**에 있다.

## 한 판의 진행 흐름 [확정]
1. 임시 본부에서 탐사를 준비한다.
2. 폐쇄된 연구소에 진입한다.
3. 걷기/뛰기를 구분해 이동한다.
4. 몬스터와 전투하거나 피한다.
5. 보물함을 발견해 운반한다.
6. 본부에 반납해 보상을 확정한다.
7. 보상으로 능력을 강화하고 더 위험한 구역을 탐사한다.

## 조작법 [확정: 액션 / 미정: 기본 키맵은 임시]
`GameAction` 기준으로 관리하고 실제 키는 `KeyBindings`에서 연결한다.

| 액션 | 임시 기본 키 | 비고 |
|------|------|------|
| MOVE_UP/DOWN/LEFT/RIGHT | 방향키 / WASD | held |
| RUN | Shift | held (전환 순간이 달리기 시작) |
| ATTACK | Space 또는 마우스 좌클릭 | pressed |
| INTERACT | E | pressed |
| PAUSE | Esc | pressed |

## 맵과 구역 [제안]
- 임시 본부: 탐사 준비 + 보물 반납 구역(DELIVERY_ZONE)
- 폐쇄 연구소: 테스트 방 1개로 시작 → 이후 구역 확장

## 몬스터 역할 [확정]
| 몬스터 | 역할 |
|--------|------|
| 슬라임 | 약한 일반 몬스터 |
| 경비원 | 순찰·추격 |
| 연구원 | 거리를 유지하는 원거리 공격 |
| 팀장 | 소음에 반응하는 엘리트. 앉아 시작, 달리기 시작 2회 또는 피격 시 분노 |

수치는 `docs/GAME_RULES.md` 참고.

## 보물과 성장 [확정: 루프 / 미정: 성장 수치]
- 보물함을 운반해 본부 반납 영역에서 반납하면 보상 확정.
- 사망 시 이번 탐사에서 **미반납** 보물은 손실. 이미 반납 완료한 보상은 유지.
- 성장: 체력 회복, 공격력·체력·운반 능력 강화. (수치 [미정])

## 성공·실패 조건 [제안]
- 성공: 보물 반납으로 보상 누적, 더 위험한 구역 공략.
- 실패: 플레이어 HP 0 → 이번 탐사 미반납 보물 손실.
- 최종 클리어 조건: [미정]
