# ROADMAP

기능 상태는 코드·테스트·실제 실행 확인을 구분해 기록한다.
완료 기능의 세부는 `PROGRESS.md`(요약)·`CHANGELOG.md`(플레이 변화)·`process.md`(작업 로그) 참고.

## 현재 상태 요약 (2026-10-23)

core 테스트 **245개** + `lwjgl3:build` 통과, 주요 플로우는 실행 캡처로 검증
(`docs/images/frames/`). 최신 커밋 `84ec3e4`까지 전부 push됨.

### 완료된 큰 축

- **기반**: Java 8 / LibGDX 1.14.2, core+lwjgl3 분리, 이동/충돌/4방향 공격/HP·사망,
  페이드 맵 전환, 세션 공유(PlayerSessionState), Mona 픽셀 폰트 전역, 배경음악·효과음 토글.
- **연구소 탐사**: V4 벽·문 통일, 방향별 가구·컨테이너 loot(E 개봉·8칸 가방·D 가치 교체),
  미니맵·H 귀환 경로·발자국, 몬스터 4종 행동 상태 기계(배회/추격/탐색/복귀),
  사망 → 소지품 상실 → 본부 재소환.
- **난이도별 시드 기반 생성**: 쉬움 16방/보통 25방/어려움 36방, 구조 틀 12종·테마 16종,
  결정적 시드(contentHash)·접근성 BFS·폴백, 100시드×3 전수 검증. 수제 쉬움 맵은 회귀 기준.
- **본부 경제·성장**: 귀환 이관 → 보관함 → 선택 판매, 영속 프로필(원자 저장+백업+마이그레이션),
  영구 강화 트리 17노드, 공통 스킬 시스템(장착/단축키/쿨다운/스킬창/퀵슬롯 HUD),
  스킬 5종(돌진·회복·충격파·전기 투척·보호막, 최대 5슬롯).
- **보스전 9단계**: 1-1 폐기물 변이체(레거시 회귀 고정) → … → 2-3 이동형 배양 탱크 순차 해금.
  1-2 이후는 데이터 주도 범용 패턴 엔진(BossBattle — 패턴 kind 12종, 예고=판정 기하,
  프레임 독립), 투기장 8종, 3×3 실루엣 선택창, LEGENDARY 보상 원자 커밋(runId 영수증),
  플레이어 스킬 수치 불변 계약(기준 회귀 테스트).
